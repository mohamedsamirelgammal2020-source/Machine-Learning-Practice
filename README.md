# Basic ML Syntax Practice: Car Price Prediction

## Overview
This repository contains a simple practice notebook to understand the basic workflow of machine learning using Python. It serves as a syntax exercise rather than a full predictive project.

## Skills & Libraries Practiced
* **Pandas:** Structuring and managing small datasets.
* **Scikit-Learn:** Understanding the syntax for initializing and fitting a `RandomForestRegressor`.
* **Matplotlib:** Creating bar charts to visualize predicted vs. existing values.
* **Business Logic:** Using conditional statements (`if/else`) to simulate business decision-making based on AI outputs.

*Note: The data used in this notebook is intentionally small and hardcoded specifically to practice library syntax and end-to-end workflow structure.*
